# Spec: repo cleanup and performance pass

Repo root `R`; the game is `O` = `demos/override`. Unit suite: `node --test demos/override/tests/*.test.mjs` from `R` (642 pass, 30.6 s at start). e2e: `cd demos/override && npm run build && npx playwright test`. Baseline: 4,776 tracked files, `public/assets` 9.4 MB, `dist` 13 MB.

## Intent

The repo is a fork of OpenBMB/AgentVerse. Only `demos/override` is developed; everything else is unused upstream code. The game itself carries dead paths, copy-paste helpers, an oversized test suite and a handful of real performance problems for a 50-player event. Done looks like: a repo that holds the game only, a demo with no legacy case format and one copy of each helper, a unit suite that is faster and smaller, and the five ranked performance fixes landed without a visible regression. User decisions: drop all upstream code; keep the game at `demos/override`; keep `*.md` plan, spec, feature, content and proto files, delete run noise; build in place on `demo/override`; nothing pushed.
